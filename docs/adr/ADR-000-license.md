# ADR-000：许可证选择 AGPL-3.0

日期：2026-10-03 · 状态：已接受

## 背景

项目定位为纯开源、自部署工具，不运营付费 SaaS。需要选择许可证并明确其含义边界。

## 决策

采用 **AGPL-3.0**。

## 理由

1. 目标用户（自部署者、小型团队）不受 AGPL 影响：自用、修改、内部分发均无需开源自己的代码。
2. 防止云厂商将本项目原样包装为托管服务而不回馈上游——AGPL 要求向网络用户提供服务时公开对应源码。
3. 生态参照：PG Back Web 同为 AGPL-3.0；Databasus 为 Apache-2.0。借用的 Apache-2.0 代码（如有）保留其原文件许可声明并在 NOTICE 注明。

## 边界（诚实声明）

- AGPL **不能**阻止符合许可证的合规托管（对方公开其修改即可），只提高搭便车成本。
- 本项目不使用"禁止商用"式非自由条款；"不做付费 SaaS"是维护者自身的运营决策，不是对他人的许可限制。

## 后果

- 所有贡献者以 DCO/CLA 之外的默认方式授权：贡献即同意以 AGPL-3.0 授权（README 与 CONTRIBUTING 注明）。
- 未来若引入 Apache/MIT 依赖，无兼容问题；反向（把本项目代码放进宽松许可项目）不适用。
