# ADR-002：不 fork Databasus，独立实现

日期：2026-10-03 · 状态：已接受

## 背景

竞品 Databasus（Apache-2.0，8.7k stars）功能覆盖广（四数据库引擎、物理备份/PITR、工作区/RBAC、agent 架构，TypeScript+Go monorepo 约 11MB 源码）。

## 决策

独立实现本项目，不 fork。Databasus 作为参考实现：读其 ADR/openspec 与恢复验证设计（引用固定 commit + 路径）；个别自包含小模块可按 Apache-2.0 规矩借用（保留原文件许可头 + NOTICE 注明 + 改动说明）；通用修复按维护成本回馈上游。

## 理由

1. 我们需要 ~2 万行级小工具；fork 得到 ~30 万行级平台，删功能比加功能更难维护。
2. 差异化方向与其架构反向：砍团队/多引擎、去 Docker socket、聚焦三平台。
3. 许可允许 fork，但改名（商标不随许可转移）与持续合并冲突均为纯开销。

## 边界

- 竞品能力是动态信息，不作为架构定论；差异化不承诺排他性（开源下他人可合法复用设计）。
- 不向竞品提交三平台向导/覆盖声明/恢复包相关改进（由本项目优先投入），通用修复不受此限。
